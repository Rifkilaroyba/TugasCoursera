# Tugas Portofolio Developer - Coursera Fullstack

Portofolio web responsif dan interaktif yang dibangun menggunakan HTML5, CSS3, dan JavaScript murni.

## 👤 Pengembang
- **Nama**: Rifki Laroyba
- **Proyek**: Tugas Coursera Fullstack Web Development

## 🚀 Fitur Utama
1. **Header & Navigasi Responsif**:
   - Menu navigasi ramah aksesibilitas (*Skip Link* dan ARIA labels).
   - Menu hamburger interaktif untuk perangkat mobile.
   - Smooth scrolling antar-bagian halaman (*Tentang Saya*, *Proyek*, *Keterampilan*, *Kontak*).
2. **Koleksi Proyek Interaktif**:
   - Filter kategori dinamis (*Semua*, *Aplikasi*, *Web*, *Data*).
   - Modal Lightbox untuk melihat gambar proyek dalam ukuran penuh beserta keyboard accessibility (Escape to close).
3. **Bagian Keterampilan (Skills)**:
   - Tampilan badge modern dengan highlight hover effect.
4. **Formulir Kontak dengan Validasi Real-time**:
   - Validasi input form interaktif (nama, email valid, panjang karakter pesan).
   - Umpan balik langsung untuk status pengiriman dan pesan kesalahan.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik & aksesibilitas WCAG.
- **CSS3**: Desain modern responsif, CSS Grid & Flexbox, transisi halus, dan tema dark mode.
- **JavaScript (ES6+)**: Logika interaksi DOM, filter proyek, modal lightbox, dan validasi form.

## 💻 Cara Menjalankan
Buka file `index.html` langsung di browser favorit Anda (misalnya Google Chrome) atau jalankan melalui live server lokal.
